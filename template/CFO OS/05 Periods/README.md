# Periods

Recurring work, filed by the period it belongs to. One folder per fiscal year, named FYyyyy. Inside it, one folder per month (yyyy-mm) and per quarter (yyyy-Qn).

```
05 Periods/
  FY2027/
    Inputs/  Working/  Outputs/  Log.md     annual work: budget, year-end and audit
    2027-03/
      Inputs/  Working/  Outputs/  Log.md   monthly work: close, management accounts, forecast critique
    2027-Q1/
      Inputs/  Working/  Outputs/  Log.md   quarterly work: board pack, quarterly accounts, investor reporting
```

The year folder is itself the period folder for annual work, so it has its own four parts beside the month and quarter folders. A month is filed under the fiscal year it falls in, which may not be the calendar year.

- `Inputs/` holds files exactly as received. Never edit them; save an edited copy in `Working/`.
- `Working/` holds drafts and workings.
- `Outputs/` holds each final output exactly as sent.
- `Log.md` records what was done, newest first, one line each: `- yyyy-mm-dd: what was done, by whom, and the files produced.`

A closed year moves to `08 Archive` once its audit is signed.
