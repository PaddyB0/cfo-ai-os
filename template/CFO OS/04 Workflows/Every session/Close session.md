# Close session

<!-- cfo-os:template begin body -->
## Trigger

The CFO says "close the session", or the work of the session is done.

## Inputs

- What was done, found, decided and corrected in this chat.
- The current `03 Memory/` files.
- The `Log.md` of the period or project worked on.

## Steps

1. List the outputs produced in this session and where each one is saved.
2. Propose new lines for `03 Memory/Decisions.md`: one per decision made in the session, dated, newest first, each with who decided and its source.
3. Propose a rewrite of `03 Memory/Key findings.md` so it states the current position, not a history. Show what is added, changed and removed.
4. Propose new lines for `03 Memory/Open questions.md`, each with an owner and when the answer is needed. Mark any question answered in this session, with the answer and the date.
5. Propose new lines for `03 Memory/Lessons.md` for every correction the CFO made in the session.
6. Propose a line for the period or project `Log.md`: the date, what was done and the files produced.
7. List any change to `00 System`, `01 Context` or `02 Rules and style` the session suggests, with the exact text. These are proposals only.
8. Show everything from steps 2 to 7 together and ask the CFO for a yes, a no, or edits to each.
9. Before writing, check whether each file has changed since you read it. If one has, show the CFO and stop.
10. Write only what the CFO accepted. For an accepted change to `00 System`, `01 Context` or `02 Rules and style`, also add a line to `03 Memory/Decisions.md` and to `00 System/Changelog.md`.
11. Tell the CFO what was written, and remind them to paste `Instructions.md` into the Project again if it changed.

## Checks every output carries

- Each figure ties to its source, or the output says it does not and why.
- The scenario and, for a forecast, the cycle are stated.
- Each figure has a source: metric, scenario, cycle and period, or the file it came from.
- The sign convention is named for every table.
- Every memory line has a date and a source.

## Output

The proposed memory and log lines in the chat, then the accepted lines written to their files.

## Where it is filed

`03 Memory/` and the period or project `Log.md`. Accepted changes to the system, context or rules also go to `00 System/Changelog.md`.
