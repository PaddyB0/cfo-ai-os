# Key findings

The current state of what we know: the handful of findings that matter now. This file is rewritten at each session close to say what is true today, not added to. History lives in `Decisions.md` and the period logs.

## Line format

`- Finding, in one sentence, with the figure that supports it. Source: link to the output or file.`

Keep it short enough to read in a minute. When a finding no longer holds, remove it here; if it led to a decision, that decision stays in `Decisions.md`.
