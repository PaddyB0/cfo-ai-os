# Decisions

Every decision that changes how the work is done or what a figure means, including each accepted change to `00 System`, `01 Context` or `02 Rules and style`. Newest first. A line is never edited or removed; a decision that is reversed gets a new line that says so.

## Line format

`- yyyy-mm-dd: the decision. Decided by: name. Source: link to the meeting note, email or output.`
