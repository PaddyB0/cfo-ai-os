# Open questions

Questions that need an answer from someone before the work can be finished or trusted. Each one has an owner. Newest first.

## Line format

`- yyyy-mm-dd: the question. Owner: name. Needed by: yyyy-mm-dd or the event. Source: where it came up.`

When a question is answered, add the answer to the end of its line with the date, and record any decision it leads to in `Decisions.md`. Answered lines are kept.
