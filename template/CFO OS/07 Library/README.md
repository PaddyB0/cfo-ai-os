# Library

Reference documents that do not belong to one period or project: signed accounts of earlier years, facility and investment agreements, accounting policies, the group structure chart, auditor letters, board minutes.

Keep each document as received; never edit it. Claude reads this folder and never writes to it. Name each file for what it is, in plain English, for example `Revolving credit facility agreement.pdf`.

When a document stops applying, move it to `08 Archive` rather than deleting it.
