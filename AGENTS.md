# AGENTS.md

Instructions for any coding agent working on this repository. `CLAUDE.md` imports this file, so the rules live in one place.

## What this is

A folder template for a finance team that works with Claude and a finance data connector, laid out by access tier, plus `cfo-os`, the tool that deploys, upgrades and checks a folder, and `SETUP.md`, the setup prompt generated from the template. Read `README.md`, then `docs/folder-map.md`, `docs/roles.md` and `docs/upgrade.md`.

- `template/CFO OS/`: the folder a finance team receives, with placeholders and template regions.
- `src/cfo_os/`: the tool. `placeholders.yaml` lists every placeholder; `ownership.yaml` gives every template path its class; `setup_prompt.md` is the source of `SETUP.md`.
- `SETUP.md`: generated by `python run.py prompt --out SETUP.md`. Never edit it by hand; regenerate it whenever the template, `placeholders.yaml` or `setup_prompt.md` changes.
- `plugin/`: the `cfo-os` Claude plugin, one folder per skill under `plugin/skills/`, with its eval suite in `plugin/evals/`. `.claude-plugin/marketplace.json` makes the repository its marketplace. Read `docs/skills.md` before adding a skill.
- `schemas/`, `examples/`, `tests/`, `docs/`.

## Rules

1. **No real company in anything.** No client name, person, figure, price, product term, entity structure, metric id or calendar date taken from a real business. Examples and fixtures are invented and say so in their first lines.
2. **Roles, not ids.** Template text names a metric or scenario role through a placeholder listed in `placeholders.yaml`. A new placeholder goes into that file and into `schemas/answers.schema.json` in the same change.
3. **Template regions.** In a `system` file, only text between `cfo-os:template begin` and `end` markers belongs to the template; upgrades replace it. Keep markers on their own lines, never nested, with ids unique in the file. Client text stays outside the markers.
4. **Every workflow** follows `Shared/Workflows/Workflow template.md`: Trigger (starting with Monthly, Quarterly, Annual or On request), Inputs, Steps, Checks every output carries, Output, Where it is filed.
5. **British English**, plain sentences, file names with spaces inside the CFO folder, normal repository names elsewhere.
6. **Python 3.11+, standard library and PyYAML only.** It must run on a locked-down Windows laptop against a OneDrive folder: keep line endings as found, no symlinks, retry on a file lock.
7. **This repository is a mirror.** The maintainer publishes it from a private source that runs extra scans. Pull requests are welcome and are ported back by hand.

## Before you finish

```
python -m pytest -q
python run.py scrub .
python run.py prompt --check SETUP.md
python run.py deploy --answers examples/answers.example.yaml --metrics examples/metrics.example.json --target "<scratch>/CFO OS" --tiers CFO,VP,Team
python run.py check --folder "<scratch>/CFO OS"
```

When the plugin's manifests change, also run `claude plugin validate --strict .` and `claude plugin validate --strict plugin`. The plugin's version is the package version.

All must pass. When a change alters template text, add a line to `CHANGELOG.md` naming the regions it changed.
